Frações EgípciasProposição 12 · algoritmo de Fibonacci-Sylvester

O problema

Fração unitária é 1/n (n inteiro positivo). Fração egípcia é uma soma de unitárias distintas, ex.: 11/12 = 1/2 + 1/4 + 1/6. O papiro de Rhind (c. 1650 a.C.) traz a tabela de 2/n para n ímpar de 5 a 101; a única fração sem unitárias era 2/3.
Piso, teto e parte fracionária: ⌊x⌋ é o inteiro k com k ≤ x < k+1; ⌈x⌉ é o inteiro k com k−1 < x ≤ k; {x} = x − ⌊x⌋ ∈ [0,1). Ex.: ⌊−π⌋ = −4, ⌈−π⌉ = −3, {√2} = √2 − 1.

Proposição 12

Toda fração p/q, com inteiros 0 < p < q, é soma de frações unitárias distintas.

O algoritmo voraz

  1. k = ⌈q/p⌉ (menor k com 1/k ≤ p/q).
  2. Subtraia: p/q − 1/k = (pk − q)/(qk).
  3. Se o resto for 0, acabou; senão repita com o resto.
Exemplo (Ex. 16): 5/7 → ⌈7/5⌉=2 → 3/14 → ⌈14/3⌉=5 → 1/70. Logo 5/7 = 1/2 + 1/5 + 1/70.

A prova, em palavras (indução forte no numerador)

Hipótese: vale para todo numerador menor que p. Seja k = ⌈q/p⌉; então k−1 < q/p ≤ k, isto é, 1/k ≤ p/q < 1/(k−1).
(i) Se 1/k = p/q, acabou.
(ii) Senão 1/k < p/q < 1/(k−1) e p/q = 1/k + p₁/q₁ com p₁ = pk − q, q₁ = qk.
• p₁ < p: de k−1 < q/p vem p(k−1) < q, logo pk − q < p.
• 0 < p₁ < q₁: p₁ > 0 porque 1/k < p/q; p₁ < p < q < qk.
• Pela hipótese, p₁/q₁ é soma de unitárias distintas, todas ≤ p₁/q₁ < 1/(k−1) − 1/k = 1/(k(k−1)) ≤ 1/k, portanto menores que 1/k. Basta somar 1/k. ∎
Nota sobre a imagem 2: a linha "p₁ = pk − p = pq − p + p − q …" parece ter uma gralha. O correto é p₁ = pk − q, e p₁ < p segue de p(k−1) < q.
